class ansys.acp.core.Layup(offset=0.0, analysis_plies=(), production_plies=(), modeling_plies=(), element_label=0, aligned=True)#

Layup information for a sampling point.

It provides details about the plies in the layup, their order, thickness, and other properties. The plies are ordered in the sampling direction. If aligned is True, the sampling direction is aligned with the element normal. Otherwise, it is aligned with the reference direction.

Note that the angle of the analysis plies is the layer angle between the fiber direction and the element coordinate system. The other angles are the design angles of the plies.

offset#

Distance between the reference surface and the bottom face of the laminate.

Type:

float

analysis_plies#

Analysis ply entries in the layup.

Type:

tuple[AnalysisPlyLayupEntry, …]

production_plies#

Production ply entries in the layup.

Type:

tuple[ProductionPlyLayupEntry, …]

modeling_plies#

Modeling ply entries in the layup.

Type:

tuple[ModelingPlyLayupEntry, …]

element_label#

Element label associated with the layup.

Type:

int

aligned#

Whether the layup is aligned with the element normal.

Type:

bool

class ansys.acp.core._tree_objects.sampling_point.LayupEntry(order, ply, angle=0.0, thickness=0.0, design_thickness=0.0, offset=0.0)#

Single ply in the layup of a sampling point.

order#

Zero-based position in the sampling direction within this ply-level list.

Type:

int

ply#

The ply object associated with this entry.

Type:

PlyT

angle#

Design angle in degrees. In case of an analysis ply, this is the layer angle between the fiber direction and the element coordinate system.

Type:

float

thickness#

Effective thickness of the ply.

Type:

float

design_thickness#

Design thickness of the ply.

Type:

float

offset#

Type:

float
